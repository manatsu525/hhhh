# 铁骑征途 · 群雄割据（安卓）

一款参照《骑马与砍杀：战团》玩法的单机触屏游戏：大地图闯荡 + 实时骑马砍杀战斗 + 六国争霸。

## 核心玩法

- **大地图**：点击移动，点击城镇/城堡/村庄进入，点击部队追击或交谈；拖动平移、双指缩放。时间只在移动或等待时流逝，有昼夜变化。
- **六个国家**：雄狮王国（重骑士）、霜狼部族（步兵、飞斧）、白桦公国（长弓、贵族骑兵）、苍狼汗国（骑射手）、金沙苏丹国（马穆鲁克）、山岭共和国（长枪、重弩）。
- **66 个据点**：每国 2 座城镇、3 座城堡、6 个村庄；36 位领主（含 6 位君主）各自带兵巡逻、追击、集结大军攻城，国家之间会宣战与议和，甚至灭亡。
- **队伍经营**：村庄招募志愿兵、酒馆雇佣佣兵；每国 10 个兵种的升级树（步兵/远程/骑兵/骑射分支）；食物、士气、每周军饷、伤员恢复、俘虏招降或出售赎金。
- **装备**：70+ 件武器、盾牌、护甲和 8 种战马，各国城镇出售本国特色装备；战利品。
- **实时战斗**：虚拟摇杆移动/骑马转向；近战挥砍（自动锁定前方敌人）、按住格挡、盾牌承伤与破碎；弓/弩/投掷武器按住瞄准松开射击，骑射有散布；**骑枪冲刺**伤害随马速大增；战马冲撞步兵；给步兵/远程/骑兵下达坚守/跟随/冲锋命令；援军分批入场、士气崩溃溃逃。也可选择自动结算（战术技能加成）。
- **攻城战**：建造攻城梯后攻城，守军弓手据城垛射击；也可协助友军守城。
- **竞技场**、**赏金任务**、**贸易**（各地特产与紧缺商品）、打劫商队、洗劫村庄。
- **争霸路线**：向国王申请成为雇佣兵 → 宣誓成为封臣获得封地；或独立攻占城堡建立自己的王国。占领所有城镇即统一大陆。
- 人物等级、4 项属性、16 项技能。

## 隐私与卸载

- 不申请任何权限（不联网、不读写外部存储）。
- 存档只保存在应用私有目录 `/data/data/com.manatsu.steedsaga/files/saves/`，禁用了云备份与设备迁移；**卸载应用时系统会把它和 WebView 数据一并删除，手机里不会留下任何文件**。

## 构建

需要 JDK 17+ 和 Android SDK（platform 34）：

```bash
cd steed-saga
./gradlew assembleRelease
# 输出：app/build/outputs/apk/release/app-release.apk
```

推送到 GitHub 后，`.github/workflows/steed-saga-apk.yml` 会自动构建并把 APK 作为 Actions 产物上传。
APK 使用调试证书签名，可直接安装；不同机器构建的 APK 签名不同，覆盖安装前需要先卸载旧版。

## 结构

游戏本体是纯 HTML5 Canvas + JavaScript（`app/src/main/assets/game/`），由一个极简的原生 WebView 外壳（`MainActivity.java`）全屏横屏运行，不依赖任何第三方库。

| 文件 | 内容 |
| --- | --- |
| `js/data.js` | 势力、物品、兵种树、商品、背景、技能 |
| `js/world.js` | 地形生成、据点/领主/部队、AI、经济、围城、外交、存档 |
| `js/mapview.js` | 大地图渲染与触控 |
| `js/battle.js` | 实时战斗引擎（近战/远程/骑乘/格挡/阵型/攻城/竞技场） |
| `js/battleui.js` | 战斗触控按键 |
| `js/ui.js`、`js/game.js` | 菜单面板与游戏流程 |
| `js/main.js` | 主循环、标题与创建角色 |

在桌面浏览器直接打开 `index.html` 也能玩（战斗中可用 WASD 移动、J 攻击、K 格挡、Q 切换武器、1/2/3 下令）。
